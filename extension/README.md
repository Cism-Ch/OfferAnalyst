# 🧩 OfferAnalyst 1-Click Capture — Chrome Extension (Manifest V3)

Extension légère pour Google Chrome, Brave, Edge et Opera permettant de capturer les offres d'emploi en 1 clic (LinkedIn, Indeed, Welcome to the Jungle, etc.) et de les injecter directement dans **OfferAnalyst**.

## 🚀 Installation Rapide (Mode Développeur)

1. Ouvrez **Google Chrome** et naviguez vers `chrome://extensions/`
2. Activez l'interrupteur **Mode développeur** (en haut à droite)
3. Cliquez sur **Charger le dossier non empaqueté** (Load unpacked)
4. Sélectionnez ce dossier `extension/`
5. L'icône OfferAnalyst apparaît dans votre barre d'extensions !

## 💡 Utilisation

1. Rendez-vous sur n'importe quelle offre (ex: LinkedIn Jobs, Indeed)
2. Cliquez sur l'icône de l'extension
3. Cliquez sur **⚡ Envoyer vers OfferAnalyst**
4. L'offre est automatiquement injectée dans l'onglet *Texte Libre* pour structuration et analyse multi-axes immédiate.
